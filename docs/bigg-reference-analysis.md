# Análisis de referencia: BIGG

## Alcance

Se revisaron 99 capturas. Varias muestran el mismo bloque mientras se despliegan sus movimientos, por lo que no representan 99 rutinas diferentes. La recopilación siguiente consolida repeticiones y conserva series, tiempos y descansos únicamente cuando resultan legibles. Sirve como referencia de producto y programación; no autoriza copiar marca, fotografías, textos descriptivos ni planes completos.

## Qué funciona bien en el producto

- El inicio combina descubrimiento con un tracker semanal visible: día planificado, realizado y objetivo `3/3`.
- Performance presenta primero números grandes: actividades, tiempo activo, bloque más elegido y marcas de carga.
- La biblioteca distingue entrenamientos guardados y bloques favoritos por tipo.
- Los filtros separan movimiento, material, músculo, deporte, tiempo y modalidad.
- Cada bloque tiene identidad propia, duración, modalidad, intención y una lista compacta. Los videos aparecen al desplegar movimientos.
- Un entrenamiento se arma con secciones sucesivas y se confirma como una unidad.

## Formatos observados

| Formato | Uso observado |
| --- | --- |
| Rondas completas | Técnica, fuerza accesoria y estabilidad |
| AMRAP | Densidad de trabajo dentro de 6–12 minutos |
| Every 60/90/120/180 segundos | Fuerza, complejos y potencia con pausa controlada |
| Intervalos 20/10 o 30/30 | Cardio y acondicionamiento |
| Escaleras, por ejemplo 16-12-8 | Trabajo metabólico |
| Bloque principal más descanso explícito | Fuerza con carga desafiante |

Para MyFitnessCoach no conviene adoptar AMRAP o intervalos intensos como opción inicial automática. Deben depender de experiencia, técnica, fatiga y objetivo.

## Propuesta para MyFitnessCoach

Un plan debería tener cuatro secciones visibles aunque su contenido cambie:

1. **Warm up, 5–8 minutos:** movilidad específica, activación y una progresión de coordinación.
2. **Bloque 1, 6–10 minutos:** potencia o transferencia cuando el usuario esté preparado; técnica y control en una sesión de baja carga.
3. **Bloque 2, 12–25 minutos:** fuerza principal. Es el bloque que debe conservarse cuando hay poco tiempo.
4. **Bloque 3, 6–12 minutos:** fuerza complementaria, estabilidad y movilidad/flexibilidad según la semana.

Para sesiones de 30 minutos se reducen accesorios, no la calidad del bloque principal. En 45 minutos se utiliza la estructura completa. En 60 minutos se agregan series o un segundo patrón de fuerza; no se llena el tiempo con ejercicios arbitrarios.

El modelo de datos debe separar:

- `Movement`: ejecución, músculos, material, esquema y video.
- `BlockTemplate`: objetivo, modalidad, duración y prescripciones.
- `PlannedBlock`: copia adaptada para una sesión concreta.
- `CompletedBlock`: resultados, comentarios y tiempo real.
- `Favorite`: movimiento o bloque guardado para la biblioteca.

El tracker semanal se puede derivar de días planificados y sesiones registradas: pendiente, parcial, completa o realizada fuera del día previsto. Performance debe mostrar adherencia respecto del plan real de esa semana, sesiones, minutos, capacidades entrenadas y evolución de cargas. No conviene usar calorías estimadas ni porcentajes de mejora inventados.

## Límites de la recopilación

- Algunas tarjetas estaban parcialmente fuera de pantalla y no se completaron por inferencia.
- Abreviaturas como MB, DDB, SDB, DKB y SKB requieren un glosario antes de mostrarlas al usuario.
- Una captura muestra “6 bloques en el día”; no significa que una persona deba completar seis bloques en una sesión.
- La biblioteca contiene bloques favoritos históricos y no permite deducir por sí sola una progresión semanal.
- Las recetas de BIGG aportan variedad, pero no prueban que cada combinación sea adecuada para nuestro usuario o para pádel.
